# BS BioTracker — 人类激素周期版

SillyTavern 生理状态追踪扩展：聚焦**人类女性**的全生命周期生理——月经周期、
受孕、妊娠、分娩、哺乳，直到更年期与停经——并把**激素状态外显到情绪、
行为与性态度**：月经期易怒、黄体晚期 PMS、排卵期性欲峰值（+该戴套的时刻）、
哺乳期母爱外溢、停经后的「第二春」……

## 版本状态

v0.11.0（fork 自 Liuuuu54/st_bs_biotracker v0.9.7 的改造版）

## 与上游 0.9.7 的差异

- **砍掉种族系统**：锁死人类。67 种族 / 5 繁殖组 / 11 衍生类型 / 混血规则、
  种族百科页、注册页种族输入与调色盘、提示词种族目录全部移除。
  精力集中在人类生理循环本身。
- **年龄→经期判定**：`bio.menarcheAge`（默认 12）前的角色没有周期（无经期、
  不可受孕），到龄自动迎来初潮；`bio.menopauseAge`（默认 45）后永久停经。
  两个门槛都可在完整变量页调整。
- **更年期阶段链**：围绝经期早期（周期不规律化 + 生育力线性衰退）→
  围绝经期晚期（稀发经期、潮热顶峰）→ 停经（永久，含「第二春」画像与
  停经后性态度）。停经角色可承接胎内回归。
- **性与避孕态度层**：主流程提示词按角色的生理阶段 + 关系状态（婚姻/情感
  对象、避孕措施、受孕意愿）注入 `[性与避孕态度]` 块——排卵期无措施的单身
  角色会被明确标注「该坚持戴套」，已婚默认顺其自然，停经+丈夫=无套自然。
  对抗模型写黄文时从不避孕的惯性。
- **哺乳期（用进废退）**：产后恢复 → 哺乳期 → 卵泡期。缓解乳意 ≥10 视为一次
  哺乳，会重置断奶计时——持续哺乳的角色哺乳期不会结束；连续 45 天
  （`bio.lactationDays`）不哺乳才退奶。哺乳期闭经（留精不孕）。
- **激素画像层（演出指令）**：主流程提示词 `[周期与激素状态]` 块——每角色的
  阶段进度（如「黄体期 第11/12天（晚段/PMS）」）、欲求档位与阶段专属派生行
  （孕期里程碑、产后 baby blues 窗口、泌乳涨感与断奶倒计时），加上在场阶段的
  **演出指引**：情绪 / 行为 / 身体三维具体指令（show-don't-tell，例如排卵期的
  蛋清样分泌物、PMS 的想吃甜食、孕中期的第一次胎动）。卵泡期/月经期/黄体期
  各分早晚段；围绝经期早期按年龄（默认停经 5 年前）触发。tracker 模型收到同一
  目录的「心理写入倾向」，写 psychology / 日记时方向与当期激素一致。
  纯派生、不持久化，随 tracker 每轮重建。
- 保留：异步 tracker 管道、快照/恢复、技能/天赋、母胎互动与胎教、
  衣橱孕压、族谱、日记、13 套主题界面。

## 环境需求

- 已知测试版本：SillyTavern `1.18.0`
- 一个可用的 OpenAI 相容 API（需稳定输出 JSON）

## 安装

1. 打开 SillyTavern → `Extensions`。
2. 使用「Install extension from Git URL」贴上本仓库地址。
3. 重新整理 SillyTavern，扩展面板出现 `BS BioTracker`。

## 快速开始

1. 打开 `BS BioTracker` 面板，在 `SYSTEM` 页填 API Base URL / Key / 模型。
2. 勾选「启用异步生理状态追踪」后保存。
3. `角色注册` 页输入角色名与补充设定（无需种族），执行注册。
4. `角色追踪` 页按「立即分析当前对话」确认 tracker 正常工作。
5. 之后自然对话即可：状态随时间推进，主模型每轮看到当期激素画像。

## 页面说明

- `條目排除`：不送入 tracker 的 worldbook 条目。
- `技能`：全局技能图鉴与角色技能/天赋。
- `角色注册`：建立角色初始状态；繁育心理推演（可选）。
- `角色追踪`：概览 / 描述 / 妊娠 / 经历 / 日记五个子页。
- `衣櫃`：衣物与穿着状态。
- `完整变量`：状态 JSON 直接查看/编辑（哺乳期时长等在此调）与时间流逝。
- `主题`：13 套界面风格。

## 设定说明

- `triggerTiming`：`after_ai` / `after_user`
- `pollMs`：轮询间隔，默认 `1800ms`
- `contextSize`：送入分析的近期消息数，默认 `10`

## 注意事项

- API 端需支援 OpenAI 风格的 `/chat/completions`；`/models` 不支援可手填模型名。
- 模型经常输出非 JSON 会导致注册与 tracker 失败。
