# BS BioTracker — 人类激素周期版

SillyTavern / TauriTavern 生理状态追踪扩展：聚焦**人类女性**的全生命周期生理——
月经周期、受孕、妊娠、分娩、哺乳，直到更年期与停经——并把**激素状态外显到情绪、
行为与性态度**：月经期易怒、黄体晚期 PMS、排卵期性欲峰值（+该戴套的时刻）、
哺乳期母爱外溢、停经后的「第二春」……

## 版本状态

v0.14.6（fork 自 Liuuuu54/st_bs_biotracker v0.9.7 的改造版）

## 这个 fork 的定位

上游是多种族魔物娘风格的繁育模拟；本 fork 逐步删成**人类单偶纯爱向的生理模拟**：

- **锁死人类**：种族/混血/衍生/人外规则全部移除，注册与调试一律归一到人类，性别只留男/女。
- **单父单源**：体内同一时间只有一名精液来源（换人即替换）。多父/精液竞争、嵌合、孕中孕、
  代孕、胎内回归、自交、异期复孕、同卵分裂均随纯爱化移除。
- **受孕向玩法清零**：高潮诱发排卵、妊娠变速、假孕期、臭意、特殊胎儿来历等机制删除，
  排卵只在排卵期自然发生（每期 1 颗），受精与着床走真实时间线。
- **纯爱≠阉割**：成人向演出内容照常露骨保留，只是叙事由「繁殖本能驱动」改为
  「关系与情感驱动」——desire 心理轴语义就是「想不想要孩子」。

## 核心机制

- **年龄→经期判定**：`bio.menarcheAge`（默认 12）前的角色没有周期（无经期、不可受孕），
  到龄自动初潮；`bio.menopauseAge`（默认 45）后永久停经。两个门槛都可在完整变量页调整。
- **更年期阶段链**：围绝经期早期（仍处周期内，年龄派生：周期开始紊乱 + 生育力线性衰退）→
  围绝经期晚期（紊乱出血段反复 + 潮热顶峰）→ 停经（永久，含「第二春」画像）。
- **性与避孕态度层**：主流程提示词按生理阶段 + 关系状态注入 `[性与避孕态度]`——排卵期无措施的
  单身角色被明确要求坚持戴套，已婚默认顺其自然，停经/无经期/哺乳闭经则无套与否只看信任与卫生
  习惯。未成年（age<18）或年龄未知的角色不生成任何性语境行。对抗模型写黄文时从不避孕的惯性。
- **性爱观与癖好画像**（`profile.sexuality`，注册时推演、工具只读）：`intimacyNeed`、`initiative`、
  `varietyTaste`、`contraceptionStyle`（不避孕/避孕套/情趣套/口服避孕药/安全期/长效措施）、
  `note`。与心理三轴、激素画像三层互补。
- **心理三轴**（mens/preg 两套，各 0-100 六段并有 stageProfiles）：mastery（月经掌控）、
  desire（想不想要孩子：0=视孕为灾→100+=生育执念）、autonomy（亲密权力关系）；
  怀孕侧为 cognition / bonding / stance。另有 isChaste / hasContraception、
  knowsFatherSource / hasProfessionalPrenatalCare 事件旗标。
- **哺乳期（用进废退）**：哺乳期闭经（可留精但不排卵、不会受孕）；缓解乳意 ≥10 视为一次哺乳，
  重置断奶计时；连续 `bio.lactationDays` 天（默认 45）不哺乳才退奶。
- **激素画像层（演出指令）**：主流程 `[周期与激素状态]` 块每轮给阶段进度、欲求档位、
  阶段专属派生行（孕期里程碑、产后 baby blues 窗口、泌乳倒计时）与在场阶段的三维演出指引
  （情绪/行为/身体，show-don't-tell）。卵泡期/黄体期分早晚段、月经期分初期/后期，
  黄体期晚段即 PMS。tracker 侧收到同一目录的「心理写入倾向」。纯派生、不持久化。
- **注册描述规则**：`normalDescription` / `pregnantDescription` 的默认字段规则可在
  注册页自定义（声音/体味/胸腹私处症状等），注册时模型按规则生成栏位；引擎会剥除
  「衣着动态/衣着自评」等已随衣柜机制移除的子字段。

## 环境需求

- SillyTavern `1.18.0` 或 TauriTavern（v0.14.x 起针对 TT 的宿主适配：欢迎页保存不再崩、
  模型拉取走 TT 宿主代理）。跨 Luker/SillyTavern/TauriTavern 三宿主。
- 一个可用的 OpenAI 相容 API（需稳定输出 JSON；也支持 Responses / Claude Messages /
  Gemini Interactions 三种自定义格式）。

## 安装

1. 打开宿主 → `Extensions`，用「Install extension from Git URL」贴上本仓库地址。
2. 重载后从🪄魔杖菜单（或扩展设置）进入 `BS BioTracker`。

## 快速开始

1. 打开面板 → `SYSTEM` 页填 API Base URL / Key / 模型并「连接并拉取模型」。
2. 勾选「启用异步生理状态追踪」后保存（默认开启）。
3. 打开目标角色的聊天 → `注册` 页输入角色名（可选先做「繁育推演」）→「注册当前角色」。
   每个聊天独立追踪，角色不注册就不会被追踪。
4. `追踪` 页可随时按「立即分析当前对话」手动跑一轮确认正常。
5. 之后自然对话即可：默认在 AI 每条回复后约 1.8 秒自动异步追踪，
   主模型每轮都会看到当期激素画像与演出指令。

## 页面说明

- `预设`：Tracker 专用预设与提示词开关。
- `排除`：不送入 tracker 的世界书条目。
- `技能`：全局技能图鉴与角色技能/天赋。
- `注册`：角色注册 / 繁育推演 / 备装 / 日记 / 初始技能，描述规则编辑也在此。
- `追踪`：概览 / 描述 / 妊娠 / 经历 / 心情五个子页 + 调试工具（含调试注入胎儿）。
- `衣柜`：衣物与穿着状态。
- `变量`：状态 JSON 直接查看/编辑、时间流逝推进、注销角色。
- `主题`：13 套界面风格与果机主题外观。

## 设定说明

- `triggerTiming`：`after_ai`（默认）/ `after_user`
- `pollMs`：轮询间隔，默认 `1800ms`
- `contextSize`：送入分析的最近消息数，默认 `12`
- `diaryRecentLimit`：送入分析的单角色最近日记数，设 0 关闭日记系统。

## 注意事项

- API 端需支持 OpenAI 风格的 `/chat/completions`；不支持 `/models` 时可手动填模型名。
- 模型经常输出非 JSON 会导致注册与 tracker 失败。
